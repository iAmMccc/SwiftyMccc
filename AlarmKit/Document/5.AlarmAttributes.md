# AlarmAttributes

`AlarmAttributes` 是 AlarmKit 的核心数据结构，它定义了 **一个闹钟 UI 的全部必要信息**：展示逻辑、元数据、主题色彩等。

用于 Live Activity / Widget UI 的数据模型，它不负责闹钟逻辑本身，而是**提供闹钟 UI 所需的完整信息**。可以把它理解为“闹钟 UI 的数据源”，包含倒计时、响铃和暂停状态的全部内容。

```swift
public struct AlarmAttributes<Metadata> : ActivityAttributes, Sendable where Metadata : AlarmMetadata {
    public typealias ContentState = AlarmPresentationState
    public var presentation: AlarmPresentation
    public var metadata: Metadata?
    public var tintColor: Color
}
```

它包含三大核心部分：

1. **`presentation`**
   系统模板化 UI 的核心内容，定义了倒计时、提醒、暂停等状态下显示的标准视图。
   系统会根据 AlarmPresentationState 自动切换 `presentation` 的展示内容。
2. **`metadata`**
   泛型扩展数据，由开发者定义。可包含闹钟标签、音效、重复周期、个性化信息等。
   通过 `metadata`，开发者可以在模板化 UI 基础上实现个性化展示。
3. **`tintColor`**
   控制系统模板的配色，提供统一的视觉风格。

## 一、`presentation` 与系统 UI

`presentation` 是系统可渲染的模板内容，例如：

- 倒计时视图（Countdown）
- 响铃视图（Alerting）
- 暂停视图（Paused）

系统根据 **`AlarmPresentationState`** 自动切换当前展示模式：

```
ActivityConfiguration(for: AlarmAttributes.self) { context in
    switch context.state.presentationState.mode {
    case .countdown:
        CountdownView(context: context)
    case .alert:
        AlertingView(context: context)
    case .paused:
        PausedView(context: context)
    default:
        EmptyView()
    }
}
```

> 🔹 重点：开发者无需自己管理状态切换，系统会自动推送 `AlarmPresentationState`。

## 二、`metadata`：开发者自定义扩展

`metadata` 是一个泛型参数，必须遵循协议 `AlarmMetadata`：

```
@available(iOS 26.0, *)
public protocol AlarmMetadata : Decodable, Encodable, Hashable, Sendable {}
```

它的作用：

- 提供可编码的自定义信息；
- 支撑个性化 UI 或业务逻辑；
- 与 `presentation` 配合使用，实现模板 + 自定义的展示。

例如定义自定义闹钟信息：

```
struct MorningAlarmMetadata: AlarmMetadata {
    var label: String
    var toneName: String
    var repeatDays: [String]
    var motivationalQuote: String
}
```

然后绑定到 AlarmAttributes：

```
let attributes = AlarmAttributes(
    presentation: presentation,
    metadata: MorningAlarmMetadata(
        label: "早起闹钟",
        toneName: "SunnyMorning",
        repeatDays: ["Mon","Tue","Wed"],
        motivationalQuote: "早起的鸟儿有虫吃"
    ),
    tintColor: .orange
)
```

在 UI 渲染时可以访问 metadata，实现个性化显示。
