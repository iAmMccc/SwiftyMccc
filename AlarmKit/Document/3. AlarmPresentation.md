# AlarmPresentation

在 **AlarmKit** 中，`AlarmPresentation` 负责描述 **闹钟在 UI 上如何展示**。它与 `Alarm` 是分离的：

- `Alarm` 描述闹钟逻辑（时间、倒计时、状态）
- `AlarmPresentation` 描述闹钟在 **不同状态下的显示内容**

> 换句话说，`AlarmPresentation` 是“闹钟的外观和交互定义”，而不是闹钟本身。

`AlarmPresentation` 包含三个主要 UI 模式：

1. **Alert**：闹钟响铃时的显示（含按钮）
2. **Countdown**：倒计时显示（含可选暂停按钮）
3. **Paused**：暂停状态显示（含恢复按钮）

## 1. Alert：响铃 UI

`Alert` 定义闹钟 **响铃时的标题和按钮**。

```swift
public struct Alert : Codable, Sendable {

    public var title: LocalizedStringResource        // 提示标题
    public var stopButton: AlarmButton               // 停止按钮
    public var secondaryButton: AlarmButton?        // 可选第二按钮
    public var secondaryButtonBehavior: SecondaryButtonBehavior?
}
```



### AlarmButton

`AlarmButton` 是 `AlarmPresentation` 中的基础单元，用于描述 **每个按钮的文案、颜色与图标**。
它既用于响铃界面的 “Stop”、“Repeat”，也用于倒计时的 “Pause”、暂停状态的 “Resume”。

```swift
public struct AlarmButton : Codable, Sendable {

    /// Text to show in a label on the button.
    public var text: LocalizedStringResource

    /// The color for the text on the button.
    public var textColor: Color

    /// The name of the icon you use on the button.
    public var systemImageName: String
}
```

`AlarmButton` 不是一个自由绘制按钮，而是一个 **语义化描述对象**，用于在系统模板中渲染出按钮样式。
这意味着它的三个属性都被严格限定：

| 属性              | 说明         | 限制                                       |
| ----------------- | ------------ | ------------------------------------------ |
| `text`            | 按钮上的文字 | 使用 `LocalizedStringResource`，支持本地化 |
| `textColor`       | 按钮文字颜色 | `SwiftUI.Color` 类型，仅影响前景色         |
| `systemImageName` | 按钮图标     | 必须是 **SF Symbols 名称**                 |

原因：

1. **系统统一外观**：AlarmKit 属于系统框架（UIKit + ActivityKit 的延伸），所有 UI 都是模板化的。
   系统会在 Live Activity / 锁屏 / 通知中自动生成 UI，而非开发者手动绘制。
2. **安全性与一致性**：
   不允许加载自定义图像资源（以防止恶意图标或违反设计规范）。
   因此，`systemImageName` 仅接受 SF Symbols 名称字符串，如 `"stop.circle"`、`"repeat"`、`"play.circle"` 等。
3. **自动暗色/亮色适配**：
   通过 SF Symbols，系统能自动调整线条粗细、颜色对比度、动画效果等。



### SecondaryButtonBehavior

这个枚举**定义了“警报界面（Alert）上第二个按钮”被点击时系统应该做什么**。换言之，`secondaryButton` 决定“长相”，而 `secondaryButtonBehavior` 决定“点下去做什么”。

```swift
public enum SecondaryButtonBehavior : Codable, Sendable, Hashable {
    case countdown   // 返回倒计时状态（snooze 或重复计时）
    case custom      // 自定义行为，不改变闹钟状态
}
```

| 情形                             | 用户点击第二按钮时发生什么                                   |
| -------------------------------- | ------------------------------------------------------------ |
| `secondaryButton == nil`         | 没有第二按钮；用户只能使用 Stop（或系统提供的其他默认动作）  |
| `secondaryButton` + `.countdown` | 自动把闹钟切回 `.countdown`（snooze），使用 `postAlert ?? preAlert` 作为倒计时时长 |
| `secondaryButton` + `.custom`    | 执行自定义动作（Intent/回调）；不改变闹钟 state（除非自定义处理者去修改） |



## 2. Countdown：倒计时 UI

`Countdown` 定义 **倒计时状态下的标题和按钮**。

```swift
public struct Countdown : Codable, Sendable {
    public var title: LocalizedStringResource     // 倒计时标题
    public var pauseButton: AlarmButton?          // 可选暂停按钮
}
```

当用户点击暂停按钮时，可以进入 `Paused` 状态。



## 3. Paused：暂停 UI

`Paused` 定义 **暂停状态下的标题和恢复按钮**。

```swift
public struct Paused : Codable, Sendable {
    public var title: LocalizedStringResource     // 暂停标题
    public var resumeButton: AlarmButton          // 恢复按钮
}
```



## 4. 结合使用

把三种状态组合成完整的 `AlarmPresentation`：

```swift
let presentation = AlarmPresentation(
    alert: alert,
    countdown: countdown,
    paused: paused
)
```

- **alert** 必须提供
- **countdown** 和 **paused** 可选，如果闹钟不支持倒计时或暂停状态，可留 nil

> 通过这种方式，Widget 或 Live Activity 可以根据 `Alarm.state` 显示对应 UI。
