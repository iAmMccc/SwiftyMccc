# Alarm - 闹钟的核心数据模型

`Alarm` 在 **AlarmKit** 框架中扮演的是**闹钟的核心数据模型**角色。它不是直接负责展示或播放提醒的对象，而是**描述一次闹钟事件的所有必要信息**，为系统的 `AlarmManager` 提供调度依据。

定义了闹钟的时间计划、倒计时逻辑、重复策略与当前状态，是 AlarmKit 的核心模型对象。

> Alarm 并非一个「运行中的对象」，而是一个**声明式模型（Declarative Model）**，描述一次闹钟的“意图”。
> 它本身不计时、不触发、不播放声音，而是作为调度数据被 AlarmKit 的系统进程或 `AlarmManager` 消化并执行。

它只要用于：

* 向系统守护进程描述一个闹钟。
* 被 `AlarmManager` 调度。
* 被UI层（如Live Activity 或 Widget） 显示。 

可以把 `Alarm` 理解成系统闹钟记录模型：

```sql
Alarm
 ├─ id: UUID
 ├─ schedule: Alarm.Schedule
 │    ├─ .fixed(Date)
 │    └─ .relative(Relative)
 │         ├─ time (hour, minute)
 │         └─ repeats (.weekly / .never)
 ├─ countdownDuration: preAlert / postAlert
 └─ state: scheduled / countdown / paused / alerting
```

| 属性                | 类型                       | 作用                                     |
| ------------------- | -------------------------- | ---------------------------------------- |
| `id`                | `UUID`                     | 唯一标识每个闹钟                         |
| `schedule`          | `Alarm.Schedule?`          | 定义闹钟何时触发（绝对时间或相对时间）   |
| `countdownDuration` | `Alarm.CountdownDuration?` | 定义倒计时阶段，如预警或贪睡时间         |
| `state`             | `Alarm.State`              | 当前状态（计划中、倒计时、暂停、响铃中） |

`Alarm` 被设计成**只作为“只读的、来自系统/守护进程的声明性模型”**，而不是一个由任意客户端直接构造并提交给系统的“命令对象”。因此库不暴露 `init(...)`，要求你通过 `AlarmManager` 或特定的配置/工厂接口去创建和注册闹钟。

> **设计模式意图**
>
> 这种设计属于**受控实例化 / 工厂模式（controlled instantiation / factory）**，常见于需要中央调度或有资源管理的系统 API。`Alarm` 是**值对象（value object）/ 数据转述（DTO）**，它来自系统，不由客户端随意 new。

## 1.状态控制 Alarm.State

```swift
/// An enum that lists all possible states of an alarm.
public enum State : Equatable, Codable, Sendable {

    /// The alarm is scheduled and ready to alert at the appropriate time.
    case scheduled

    /// The alarm is counting down to its alert time.
    ///
    /// Alarms are in this
    /// state when they are requested with a countdown duration, or when
    /// a person snoozes the alarm.
    case countdown

    /// A person paused the countdown.
    case paused

    /// The alarm is currently firing.
    case alerting
}
```

用来描述闹钟当前处于哪种状态：

* **scheduled**： 已计划，等待触发。
* **countdown**： 正在倒计时中，包含贪睡中。
* **paused**： 被用户暂停。
* **alerting**： 正在响铃中， 



## 2.  时间计划 Alarm.Schedule

```swift
/// A list of all types of schedules that the framework supports.
public enum Schedule : Codable, Equatable, Hashable, Sendable {

    /// A one-shot alarm that fires at a specific time, not a time
    /// relative to the current time zone.
    ///
    /// You can use `fixed` for events where the time won't
    /// vary based on where the person is located. For example, like
    /// alerting the time of a sports game.
    case fixed(Date)

    /// An alarm that can repeat and fire at a time relative to the device's
    /// current time zone.
    ///
    /// You can use `relative` for events which need to take into
    /// account the current time zone. For example, a wake up alarm.
    case relative(Alarm.Schedule.Relative)
}
```

`Alarm.Schedule` 描述闹钟“什么时候触发”的所有可能方式。它支持两类时间模型：

| 时间类型             | 描述                                             | 补充                                                       | 适合场景                                     |
| -------------------- | ------------------------------------------------ | ---------------------------------------------------------- | -------------------------------------------- |
| `fixed(Date)`        | 绝对时间（与时区无关，事件在那个确切的瞬间发生） | 一次性的                                                   | 适合像“比赛开球时间”这种固定瞬时事件。       |
| `relative(Relative)` | 相对本地时区的时间（按小时/分钟 + 可选重复规则） | 支持 `.never`（单次）或 `.weekly([...])`（循环）重复模式。 | 适合日常闹钟（每天 07:30）或每周重复的闹钟。 |



### 相对本地时区的触发计划 - Alarm.Schedule.Relative

```swift
/// An object that describes when an alarm alerts, relative to the device's timezone.
public struct Relative : Codable, Equatable, Sendable, Hashable {
        
    /// The cadence at which the alarm repeats, if any.
    public var repeats: Alarm.Schedule.Relative.Recurrence
    
    /// The hour and minute at which the alarm alerts, relative to the
    /// device's current timezone.
    public var time: Alarm.Schedule.Relative.Time
    
    /// Creates an alarm that fires at a specific time.
    /// - Parameters:
    ///   - time: The time at which the alarm will alert.
    ///   - repeats: The cadence at which the alarm repeats, if any.
    public init(time: Alarm.Schedule.Relative.Time, repeats: Alarm.Schedule.Relative.Recurrence = .never)
    
}
```

表示“在本地时区的某个时刻触发”，包含两个核心部分：

### 时刻触发 Relative.Time

```swift
/// An object that describes the hour and minute at which an alarm alerts.
public struct Time : Codable, Equatable, Sendable, Hashable {
    
    /// The hour mark the alarm alerts.
    public var hour: Int
    
    /// The minute of the hour the alarm alerts.
    public var minute: Int
    
    /// Creates an instance of time.
    /// - Parameters:
    ///   - hour: The hour at which the alarm will alert.
    ///   - minute: The minute of the hour at which the alarm...
    public init(hour: Int, minute: Int)
}
```

表示设备本地时间的某个精确时刻：

- `hour: Int`、`minute: Int` —— 精确到分钟的本地时间点（例如 7:30 表为 hour = 7, minute = 30）。

- 构造器 `init(hour:minute:)`，并实现 `Codable`/`Hashable`/`Equatable` 以便序列化和比较。

  

### 重复规则 Relative.Recurrence

```swift
/// Describes the cadence at which an alarm will repeat, if any.
public enum Recurrence : Codable, Equatable, Sendable, Hashable {
    
    /// An alarm that repeats weekly, on the specified day.
    case weekly([Locale.Weekday])
    
    /// An alarm that never repeats.
    case never
}
```

- `case weekly([Locale.Weekday])` —— 指定一周中哪些星期触发（数组形式）。例如周一到周五、或仅周六周日等。
- `case never` —— 不重复（只在最近的下一个该时刻触发一次）。
- `Locale.Weekday`：此类型来自系统/地区表示 weekday。实现时注意与 `Calendar` 的 weekday 数字（1..7，通常 1 = Sunday）做映射。



## 3. 倒计时控制 Alarm.CountdownDuration

```swift
public struct CountdownDuration : Codable, Sendable, Equatable {

    /// The duration applied before the alarm fires.
    ///
    /// For example, this would be the duration of a timer.
    public var preAlert: TimeInterval?

    /// The duration applied after the alarm has alerted at least once and
    /// moves back to the countdown state.
    ///
    /// For example, this would be the snooze duration for an alarm.  A
    /// timer with a repeat button could set this value to be the same as
    /// `preAlert`, or it could leave the value as `nil`.  If the value is
    /// `nil` we will use the `preAlert` duration for post-alarm countdowns.
    public var postAlert: TimeInterval?

    /// Creates an instance of a countdown duration.
    /// - Parameters:
    ///   - preAlert: The duration applied before the alarm fires.
    ///   - postAlert: The duration applied after the alarm has alerted at least once and
    /// moves back to the countdown state.
    public init(preAlert: TimeInterval?, postAlert: TimeInterval?)
}
```

`Alarm.CountdownDuration` 是 `Alarm` 的子类型，用来**描述闹钟的“倒计时”行为**，它只是一个纯数据模型，告诉系统或上层逻辑在闹钟触发前后应当计时多长时间。它是 `Codable`、`Sendable`、`Equatable`，因此可以序列化、并发安全传递并做比较。

| 属性        | 类型            | 说明                                                         | 示例                                                         |
| ----------- | --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| `preAlert`  | `TimeInterval?` | 闹钟“触发”时，显示或维持的倒计时时长（以秒为单位），倒计时结束再响铃。 | `10` 表示在闹钟时间开始倒计时，进行10秒倒计时，倒计时结束正式响铃。 |
| `postAlert` | `TimeInterval?` | 闹钟曾经响过一次或进入 alert 后，再回到倒计时状态时（例如按了 snooze/贪睡），下一轮倒计时的时长。 | 若为 `nil`，系统将**使用 `preAlert` 的值作为后续倒计时时长**（即默认贪睡时间等于原计时时长）。 |



### 常见用法举例

1. **10 秒计时器**（立即开始倒计时）：

```
let duration = Alarm.CountdownDuration(preAlert: 10, postAlert: 10)
```

表示：计时器初始倒计时 10 秒，触发后如果重复（repeat），再次进入倒计时的时长同样为 10 秒。
适合如「循环计时器」场景。



2. **普通闹钟 + 9 分钟贪睡**：

```
let duration = Alarm.CountdownDuration(preAlert: nil, postAlert: 9 * 60)
```

表示：闹钟本身不是通过倒计时触发（而是由 `schedule` 定义的时间触发），
但当用户选择贪睡（Snooze）时，将在 9 分钟后再次响起。
典型的「早上 7:30 闹钟 + 贪睡 9 分钟」行为。



3. **初始倒计时 30 秒，snooze 使用默认（等同于 preAlert）**：

```
let duration = Alarm.CountdownDuration(preAlert: 30, postAlert: nil)
```

表示：倒计时初始 30 秒，闹钟响起后如果再次进入倒计时（例如用户点击“再来一次”或“延迟”），
系统会自动使用与 preAlert 相同的 30 秒作为再次倒计时的时长。
即 postAlert = preAlert。



4. **完全依赖时间计划触发（无倒计时）**：

```
let duration = Alarm.CountdownDuration(preAlert: nil, postAlert: nil)
```

表示：没有预先倒计时，也没有贪睡时长。
闹钟完全依赖 `schedule`（绝对时间或相对时间）决定何时响起。
适合像“早上 7:30 每天响一次”的固定时间闹钟。
